## Mkcloud 的“上云互联”专线到底是什么

Mkcloud 是 2023 年上线的国内跨境专线服务商，产品线覆盖 IEPL、IPLC 和 IX 三类专线 VPS，上云互联优化专线就是其中的 IX 系列。它的做法和传统专线不太一样：每台 VPS 分配一对独立 IPv4，一个入口 IP、一个出口 IP。你从云服务器连入口进 VPS，VPS 向境外发起的访问走优化通道从出口出去，香港出口端内延迟参考 1~2ms，日本方向 25~28ms。

关键限制写在前面：入口只允许特定云厂商的 BGP 网络连入，也就是必须有一台“前置云机”做跳板；出口只出不进，不能用来建公开网站、跑回调或游戏服务端。它优化的是“你的业务服务器向境外发起的访问”，比如店铺后台、素材上传、授权 API 调用这些出站场景。

## IX 入口和直连专线的差别，是理解价格的起点

Mkcloud 的直连产品（IEPL/IPLC）按省份做白名单，开通后只允许一个省份的 IP 连入，可以修改；IX 上云专线不限省份，但强制要求云厂前置。两者对比如下：

| 维度 | IX 上云互联专线 | 直连专线（IEPL/IPLC） |
| --- | --- | --- |
| 接入限制 | 仅限指定云厂网络连入 | 绑定一个省份，可修改 |
| 是否需要云机 | 必须有符合范围的前置云机 | 不强制 |
| 出口能力 | 只出不进 | 同样不接收入站 |
| 成本构成 | 套餐 + 云前置费用 | 按套餐和本地接入评估 |
| 代表线路 | 深港/沪港/沪日/沪美 IX | 广港 IEPL、沪港 IPLC |

所以 IX 套餐标价 158 元，不代表总花费就是 158 元，还要加上你已经有的（或新买的）云服务器费用。反过来，如果你本来就租着云主机，IX 入口等于把你现有的云资源直接接到专线出口上，这部分前置成本就省了。

## 购买前必须确认的接入条件

这部分比价格更容易踩坑，下单前逐条对一遍：

1. **实名认证**：需要中国大陆手机号、真实姓名和身份证号，按《网络安全法》要求完成“手机验证码 + 身份证信息 + 邮箱验证”三重核验，海外身份无法下单。
2. **前置云机**：上海入口支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云、UCloud 华东；深圳入口支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云华南。普通 BGP 主机不能当前置。深圳入口的购物车页面当前标注阿里云接入暂时不通，具体哪家云哪家地域可用，以下单页提示为准。
3. **用途合规**：所有产品按中国法律实名，禁止机场、回国等违规用途，违规清退不退款。
4. **计费规则**：流量双向统计，超量停机；升降级都要走工单，降到低价套餐时差价不退。

## 常见问题

**158 元是一个月还是一年的价格？**
是月付价格，对应深港上云互联入门档（2核4G/1Gbps 峰值/2TB 月流量）。年付和季付部分档位有，价格以购物车选择周期后的显示为准。

**没有云服务器能用吗？**
IX 系列不行，入口只接受指定云厂网络连入，前置云机是硬性条件。没有云机的用户可以看直连 IEPL/IPLC 产品，那些按省份白名单接入，广港 IEPL 月付 228 元起。

**上云互联专线能用来做什么？**
官网知识库列的典型场景包括店铺后台操作、素材上传、直播推流、授权 API 调用、海外 SaaS 访问和游戏客户端测试。它不加速买家访问你店铺的页面，也不能保证账号永不被风控，这两点官方写得很直白。

**共享峰值和独享带宽差在哪？**
共享是峰值速率，高峰时段不保证一直跑满；独享是固定速率、不限流量。月流量几十 GB 到几 TB 的业务选共享，持续大带宽传输选独享。

**购物车里那个 999999 元的套餐是什么？**
那是独享线的定制报价占位，带宽、配置都按需求谈，不是真的要按这个价格付款。

**香港方向和日本方向怎么选？**
看目标业务在哪。后台主要连香港选深港或沪港，深港延迟更低但必须有深圳可用的前置云；日区业务选沪日。两边都有业务的，按各自方向的入口分开买，别指望一条线全加速。
